# 盲评：档位能否被分辨（2026-11-03）

## 设置

- 两组，各 4 份产出，同一任务、同一模型，只换档位；
- 随机重命名为 A–D，裁判只看内容（映射在 `mapping.md`，未给裁判）；
- 裁判是独立子会话，只按评分维度打分并回答“哪份像默认”。

## set1：创意任务（round4B）

映射：A = divergent-2，B = balanced-1，C = divergent-1，D = divergent-3。

| 裁判判断 | 结果 |
|---|---|
| 最像“没有额外风格设定” | **B** → 实际就是 balanced ✅ |
| 最像“被要求多想几个方向” | **C** → 实际是 divergent-1 ✅ |

## set2：整理任务（round4A）

映射：A = faithful-1，B = faithful-2，C = faithful-3，D = balanced-1。

| 裁判判断 | 结果 |
|---|---|
| 最像“默认整理” | **D** → 实际就是 balanced ✅ |
| 最像“要求保留原话、不做判断” | **C** → 实际是 faithful-3 ✅ |

## 解读

- 两组都把 balanced 认出来了（2/2），说明发散/忠实确实留下了可感知的“签名”，不是只存在于提示词里；
- set1 裁判给 balanced 的评语是“恰好 3 条、无标签体系、结构对称、措辞最平”——正是我们期望的“默认不抢戏”；
- set2 裁判给 balanced 的评语是“按议题归纳、句子通顺化、内联待确认”——正是 faithful 想避免的加工方式；
- 长度不是唯一线索：set1 的 balanced 不是最长的那份（D 最长），裁判仍选了它。

## 局限

- 每组只有一个裁判，且与生成模型同族，存在同源偏好；
- 四选一，猜对的概率是 1/4；两组全中，但样本小；
- 裁判能看到排版与长度，虽然我们确认长度不是决定因素。

## 结论

**档位是可分辨的**：在去掉标签、打乱顺序后，裁判仍能在两组中正确指出“默认档”和“被要求特定风格的那份”。这比单纯的评分表更能说明插件在改变行为。
