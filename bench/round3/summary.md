# 第三轮对照实验（2026-11-03）

## 本轮改动

- `faithful`：open questions 变成**硬性要求**——有矛盾/缺失/歧义就必须列，没有就写 `None.`；
- `divergent`：加了“至少一个反常规选项 + 说明代价”“近重复就换掉”；
- 任务 B 去掉了“不要改其它内容”的约束，用来真正测编辑纪律。

## 任务 A：整理会议记录（3 次/档）

| 文件 | 条目数 | open questions | `[as written]` | 总结/新增判断 |
|---|---|---|---|---|
| balanced-1 | 4 | 无 | 无 | 无 |

| balanced-3 | 4 | 无 | 无 | 无 |
| divergent-1 | 4 | 无 | 无 | 无 |

结论：

- **硬性规则生效**：忠实档 3/3 都列了 open questions（上一轮 2/3）。
- **但会过度标注**：faithful-2 把「会议日期、负责人、测试计划」也列为缺失——这些原文根本没提，属于我规则里 `date/owner` 括号带来的副作用。
- 平衡/发散 6/6 仍然不标注矛盾，符合它们“不做额外判断”的定位。

## 任务 B：只改一行代码（无额外约束，2 次/档）

6 个文件全部**只改了 1 行**（`return 1` → `return 2`），文件仍是 8 行，没有新增注释、重构或测试：

| 档位 | 结果 |
|---|---|
| divergent ×2 | 1 行 |
| balanced ×2 | 1 行 |
| faithful ×2 | 1 行 |

**任务本身不够“有越界空间”**：把 1 改成 2 太明确，模型天然只改这一行。要测编辑纪律，需要一个“怎么改都说得通”的任务（例如“给这个模块加日志”，看它会不会顺手加抽象层）。

## 总判断

1. 机制稳定：切档 → notice → 下一步规则生效，忠实档的行为可复现。
2. 提示词改动有效：硬性规则把忠实档从 2/3 提到 3/3。
3. 但需要收窄：忠实档不应发明原文没提的缺失项。
4. 发散档的新规则在这两个任务上都测不出来（一个不是创意任务，一个太简单）。

## 下一步

1. 收窄 faithful 规则：只列原文**自己提到但没说明**的事实（如“没说哪个版本”），不新增“会议日期/负责人”这类原文未涉及的字段。
2. 用一个真正的创意任务测 divergent 的新规则（例如“给这个插件想 3 个下一步实验”）。
3. 用一个有越界空间的代码任务测编辑纪律。
