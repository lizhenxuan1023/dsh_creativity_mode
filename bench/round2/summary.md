# 第二轮对照实验（2026-11-03）

## 设置

- 任务 A：把 4 条会议记录整理成 Markdown 列表（**没有**要求保留原话、不总结）。
- 任务 B：只把 `foo()` 的 `return 1` 改成 `return 2`（**没有**要求最小改动）。
- 每个档位：任务 A 跑 3 次，任务 B 跑 2 次。
- 子会话第一步先调用 `set_creativity`；`balanced` 是 no-op（对照组，不会收到 style notice）。

观察：

- 9/9 都保留了四条原始记录，没有一条擅自总结或补全版本号——**这个任务太简单，所有档位都做对了**。
- 唯一稳定差异：忠实档 2/3 会额外加 `## open questions` 并标 `[as written]`，balanced / divergent 0/6 这么做。
- 措辞差异：部分文件句末补了句号，与档位无关。

任务 A 结论：**忠实档的“标注矛盾、不替你消解”确实出现，但出现率 2/3；在简单格式化任务上，三档差别很小。**

## 任务 B：只改一行代码

6 个子会话（divergent ×2、balanced ×2、faithful ×2）全部**只改了 1 行**，文件仍是 8 行：

| 文件 | 改动行数 | 其它改动 |
|---|---|---|
| divergent-1.js | 1（`return 1` → `return 2`） | 无 |
| divergent-2.js | 1 | 无 |
| balanced-1.js | 1 | 无 |
| balanced-2.js | 1 | 无 |
| faithful-1.js | 1 | 无 |
| faithful-2.js | 1 | 无 |

**这个测试设计有问题**：提示里写了「不要改其它任何内容，不要新增文件」，等于替模型做了约束，三档自然都一样。它证明的是「显式约束被遵守」，不是「档位改变了编辑纪律」。要测编辑纪律，得给一个**没有约束**的任务（比如“把返回值改成 2”，不提任何限制）。

## 结论

1. **机制有效**：切档 → notice 注入 → 下一步提示词里有对应规则，三档的产出确实可区分（忠实档额外标 `[as written]` / open questions）。
2. **效果幅度取决于任务是否“欠说明”**：
   - 任务给足约束时（任务 B），三档收敛，差别为零——这是好事，说明它们都听指令；
   - 任务欠说明时（任务 A 没说要不要保留原话），忠实档 2/3 会主动标注矛盾，其它档 0/6。
3. **忠实档不稳定**：3 次里 1 次只保留、没标 open questions。规则里应把它变成硬性要求。
4. **发散档的差异最弱**：任务 1 多给了 1 个实验，任务 2 只多了标题结构；没有出现“明显更大胆”。

## 建议的下一步

1. 把 faithful 的「有矛盾/缺失就列 open questions」改成必做项，再测 3 次，看是否 3/3。
2. 给 divergent 加一条可检查的硬要求（例如“至少一个反直觉选项，并说明代价”），再测。
3. 用**欠说明**的任务重测编辑纪律（去掉“不要改其它内容”这类约束）。
4. 每格至少 3 次、盲评；现在的结论只能算方向性。
